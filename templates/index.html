NEXORA — BCA & Data Science Project Report

Digital Behavior Intelligence Engine

1. Problem Statement

Contemporary digital activity monitoring systems routinely infringe on end-user privacy by logging keystrokes, capturing screen feeds, and intercepting clipboard payloads. There is a pressing necessity for an ethical, privacy-preserving behavioral analytics engine that quantifies workflow rhythm and ergonomic stability without accessing or storing any private personal content.

2. Objective

To architect and deploy a full-stack digital behavior intelligence engine that translates aggregate interaction telemetry (mouse movement, scroll impulses, keystroke counts, process shifts) into interpretable cognitive workflow metrics (Focus Index, Continuity Index, Interaction Stability, Fragmentation Index) alongside unsupervised anomaly detection.

3. Data Collection

The collection daemon gathers only anonymous interaction tallies: mouse click count, mouse travel distance, keyboard event count, scroll count, active seconds, idle seconds, and application transition frequency. No typed characters, passwords, messages, window titles containing private content, or video frames are ever recorded.

4. Data Cleaning

Raw temporal timestamps are normalized against session durations. Outliers originating from suspended machine states are bounded, missing telemetry values are imputed with median session distributions, and non-numerical anomalies are filtered through schema validation.

5. Feature Engineering

Transparent deterministic mathematical formulations produce standardized indices:

  • Focus Index: (active_time / duration) * 100
  • Idle Ratio: (idle_time / duration) * 100
  • Switch Frequency: app_switches / (duration / 60)
  • Activity Density: (mouse_clicks + keyboard_events + scroll_events) / active_minutes
  • Continuity Index: Bounded inverse penalty function accounting for switch frequency and idle duration.
  • Fragmentation Index: Linear compound metric of task switches and active-to-idle disruption ratios.
  • Interaction Stability: Equilibrium assessment between input modalities (pointer vs keyboard cadence).

6. Exploratory Data Analysis & Visualization

Multidimensional visualization through Chart.js charts temporal distribution patterns, application duration hierarchies, stability trajectories, and correlation heatmaps between task switching and focus retention.

7. Machine Learning Architecture

Supervised multi-class behavioral classification is powered by an ensemble Random Forest classifier paired with K-Means clustering for unsupervised cluster validation. Hyperparameters are selected to maximize class separability across DEEP WORK, NORMAL WORK, FRAGMENTED WORK, EXPLORATION, and IDLE classes.

8. Anomaly Detection

An Isolation Forest engine establishes a dynamic multidimensional behavioral baseline. Sessions presenting anomalous deviation in input density or fragmentation trigger an alert with explicit feature contribution analysis.

9. Ethical Boundaries & Limitations

Strict Academic Notice: NEXORA analyzes digital interaction patterns exclusively. The system makes zero diagnostic claims regarding mental health, cognitive ability, psychological disorders, emotions, or medical conditions.

10. Future Scope

Integration with cross-platform native kernel events, federated local model updates, adaptive ergonomic break recommendations, and edge-device hardware acceleration.
